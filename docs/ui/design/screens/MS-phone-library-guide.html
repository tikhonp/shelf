Tagging guide

How Navidrome sees an album

  • Navidrome groups music by tags alone, and ignores folder and file names.
  • An album holds together when every track has the same Album and Album Artist.
  • A multi-disc album stays one album while every disc keeps the same Album.

Working through an album

  1. Press Fix on each issue. A Fix stages edits and writes nothing.
  2. Set Album Artist first, on All tracks.
  3. Take suggestions one by one. Release fields all come from one release, so their IDs can't mix.
  4. Read the amber fields, then press Save. One Save is one undo step.
  5. After the scan, check the album in Navidrome under Get Info, Raw Tags.

Tags every track needs

  • Every track needs Title, Artist, Album, Album Artist and Track. Genre, dates and Disc are optional.
  • Set Album Artist even when it matches Artist.
  • Replace blanks and values such as Unknown Artist with real ones.
  • Keep spelling the same everywhere. A trailing space or different capitals make a duplicate.

Several artists

  • ARTISTS and ALBUMARTISTS hold one artist per value, and Navidrome never splits them. They are the preferred way.
  • ARTIST then stays the display name, such as Alice feat. Bob.
  • ARTIST alone gets split on / feat. ft. and ; with spaces around them. AC/DC stays whole, and Foo; Bar breaks.

Compilations

  • Album Artist is Various Artists, and the compilation flag is on for every track.

Dates

  • A date is YYYY, YYYY-MM or YYYY-MM-DD.
  • RELEASEDATE is this edition, ORIGINALDATE is the first release, and DATE is the recording date. A plain YEAR counts as the release date.
  • While ORIGINALDATE is set and no release date exists, Navidrome reads DATE as the release date.

Covers

  • A cover of 500x500 to 1000x1000 is plenty. shelf stops embedded art at 1000x1000 and keeps the folder file at full size.
  • Navidrome shows the folder cover first, so a cover edit changes both.
